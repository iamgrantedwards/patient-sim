## Play locally or download

From the repository root: `uv sync --locked`, then `uv run python -m src.review`.
Open http://127.0.0.1:8765. Read-only playback and saved assessments/reviews need no
provider credentials. GitHub file pages provide raw/download access for OGG files.

[manifest.json](manifest.json) records SHA-256 and byte length for all 227
published artifacts. All 46 original OGG recordings fully decoded during
the publication audit. Files are byte-identical to their local originals. Decoding
verifies file integrity, not voice quality or an independent listening review.

The historical meta.json listened_by_human field is capture-time provenance. Current
human decisions are in fingerprinted review.json revisions. AI scores are provisional;
neither a score nor a spoken confirmation verifies the office's backend.

Patient facts are synthetic. Text/metadata passed a check against local credential
values and secret scanning. Runtime logs, incremental event journals, locks, dispatch
internals and credentials remain local. No audio was edited or silently redacted.
